# 🪐 Solar System Explorer

An immersive, CSS-driven educational web application built to explore the planets of our solar system. Built completely using vanilla **HTML5** and **CSS3** (utilising 3D transforms, radio-button state architecture, and perspective rendering), this project lets users tour celestial bodies, view orbital distances in AU, inspect orbiting moons, and open detailed fact-sheets[cite: 13, 14].

## ✨ Features

* **Pure CSS 3D Solar Model:** Built using CSS 3D perspective transforms, perspective framing, and smooth rotational animations without complex JavaScript physics engines.
* **Interactive Planet Navigation:** A sidebar navigation menu linked via CSS states lets users instantly transition across planets from Mercury to Pluto[cite: 13, 14].
* **Orbital Trajectories & Moons:** Visualises orbital paths and natural satellites (moons) for planets like Earth, Mars, Jupiter, Saturn, Uranus, and Neptune[cite: 13, 14].
* **Detailed Info Panels:** Expandable sliding panels for each planet complete with descriptions, discovery facts, historical context, and high-resolution imagery[cite: 13, 14].
